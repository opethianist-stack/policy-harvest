# 개인정보처리방침 (policy-harvest)

policy-harvest는 부서 내부 업무용 도구로, 공공기관·부처·시도교육청이 누리집에 공개한 정책문서를 모아 부서 구글 드라이브 폴더와 구글 시트에 정리한다.

## 수집하는 정보

- 개인정보를 수집하지 않는다
- 구글 계정 권한은 부서 공통 계정 하나에만 쓰며, 해당 계정의 드라이브 정책문서 폴더에 파일을 올리고 승인용 구글 시트를 읽고 쓰는 데만 사용한다

## 보관과 제3자 제공

- 인증 정보(리프레시 토큰)는 GitHub 저장소의 암호화된 Secrets에만 보관한다
- 수집한 문서와 시트 내용은 제3자에게 제공하지 않는다
